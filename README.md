# Gemini Folders

在 Gemini 網頁側欄加入「我的資料夾」，以資料夾、子資料夾與批次移動整理聊天。介面使用繁體中文，支援深色與淺色主題。

## 已實作

- 最多三層的資料夾：新增、改名、搬移、顏色、展開與收合。
- 聊天標題搜尋、多選及批次移動、將目前聊天加入資料夾。
- 刪除分類後，聊天回到未分類；保留 Gemini 原始對話。
- 每個 Google 帳號使用獨立的本機工作區，多分頁寫入依序處理。
- JSON 備份、匯入預覽與聊天分類衝突選項；匯入前下載目前工作區備份。
- 插件工具列可開啟獨立管理頁；側欄無法掛載時有浮動入口。

## 開發與建置

使用 Node 22.17.0 及 pnpm 10.16.0。版本已在 `.node-version`、`engines`、`packageManager` 與 lockfile 中固定。

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm check
pnpm zip
```

`pnpm dev` 啟動 WXT 開發模式，不會自動啟動瀏覽器或安裝插件。`pnpm preview` 啟動僅使用範例資料的本機介面預覽，網址為 `http://127.0.0.1:4173`；此預覽不會讀取或修改 Gemini 資料。

## 在 Brave／Chrome 載入

1. 先執行 `pnpm build`，產物在 `.output/chrome-mv3/`。
2. 在 Brave 開啟 `brave://extensions`，Chrome 則開啟 `chrome://extensions`。
3. 啟用「開發人員模式」，選「載入未封裝項目」，選取 `.output/chrome-mv3/`。
4. 重新整理已登入的 Gemini 網頁，展開側欄。
5. 在「筆記本」與「全部」之間找到「我的資料夾」，點「整理」開始分類。

插件更新後，先在擴充功能管理頁重新載入插件，再重新整理 Gemini 分頁。初版適用桌面 Chromium 120 以上版本；Brave、Chrome 與 Edge 的實際安裝驗證狀態見下方。

## 資料範圍與保存

- 只收錄已開啟，或 Gemini 側欄已載入且能辨識的聊天。插件中的「全部」「未分類」只表示已收錄資料，不是 Google 帳號的全部歷史紀錄。
- 保存聊天識別碼、標題、連結、分類與資料夾設定，不保存訊息正文。搜尋限於已收錄的標題及資料夾名稱。
- 使用 `chrome.storage.local`。不設後端、不需要 API key、不讀取 cookie，也不把資料傳送到第三方服務。
- 為辨識工作區，插件暫時讀取頁面上的 Google 帳號標籤，將電子郵件正規化後在本機計算 SHA-256 作為工作區識別；原始電子郵件不寫入儲存區。顯示名稱保存在本機。
- 帳號無法辨識時暫停自動收錄與分類寫入。若偵測到同一頁面內切換帳號，需重新整理 Gemini 後再操作，避免將尚未更新的側欄清單誤歸到新帳號。獨立管理頁可明確選擇工作區，或建立手動工作區來管理匯入的備份。
- 獨立管理頁開啟聊天時，由 Gemini 目前登入的帳號決定能否存取；請先切換到對應帳號。
- 同一資料夾不會讓 Gemini 自動共用對話記憶、指令或知識檔案。
- 移除插件會清除本機資料，請先匯出備份。備份含聊天標題與連結，應妥善保存。

## 驗證狀態

已透過 Brave 的登入頁面確認聊天路徑、Google 帳號標籤，以及 `mat-sidenav`、`expandable-section` 側欄結構。`pnpm check` 通過 lint、嚴格型別檢查、28 項單元／整合測試與正式建置；另已驗證 frozen lockfile 離線安裝與 ZIP 封裝。測試涵蓋分類規則、備份驗證、跨分頁序列寫入、帳號隔離及主要 UI 操作。

尚待載入插件後，在 Brave 進行實際整合冒煙驗證；Chrome／Edge 尚未進行實機測試。Gemini 介面改版可能使側欄辨識失效，屆時仍可從工具列開啟獨立管理頁整理已保存的資料。

完整需求與驗收規劃見 [PLAN.md](./PLAN.md)。
